# E-Bike

Kleine MCF-Application zur Berechnung des Übersetzungsverhältnisses eines E-Bikes mit einem Kettenrad und 10 Ritzeln inkl. grafischer Darstellung.

## Start

Die Anwendung ist als statische Web-App umgesetzt.

1. Datei `/home/runner/work/E-Bike/E-Bike/index.html` im Browser öffnen.
2. Kettenrad-Zähne und 10 Ritzel-Zähne eingeben.
3. Auf **Berechnen** klicken.

## Berechnung

Übersetzungsverhältnis je Gang:

`Übersetzung = Kettenradzähne / Ritzelzähne`
