# E-Bike

Kleine MCF-Anwendung zur Berechnung des Übersetzungsverhältnisses eines E-Bikes mit einem Kettenrad und 10 Ritzeln inkl. grafischer Darstellung.

## Start

Die Anwendung ist als statische Web-App umgesetzt.

1. Datei `index.html` aus dem Projektordner im Browser öffnen.
2. Kettenrad-Zähne und 10 Ritzel-Zähne eingeben.
3. Auf **Berechnen** klicken.

## Berechnung

Übersetzungsverhältnis je Gang:

`Übersetzung = Kettenradzähne / Ritzelzähne`
